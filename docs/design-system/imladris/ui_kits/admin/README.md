# Retired admin UI kit

This upstream survey kit was retired on 2026-08-03. The local mirror retains
this pointer for old links; its interactive source files are not vendored here
and its screen descriptions are not current product status.

The production owners are the ten `templates/admin-*` screens, unified by
`components/admin/AdminNav`. See [`RETIRED.md`](../../RETIRED.md) for the
retirement record and [`PRODUCTION.md`](../../PRODUCTION.md) for the current
consumer contract.

Do not recreate or hand-sync this kit. Use the owning PHP templates and current
application behavior when reviewing operator surfaces.
