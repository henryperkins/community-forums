branding release record `a75eee98` before any build. This release updates the
Node dependency tree and corrects two test fixtures. Production PHP, templates,

The local npm audit reports zero vulnerabilities across all severities.

## Composer destination diagnosis

The original destination-picker test failed on the shipped code at both
Chromium viewports. It created a title-only draft on General and then opened
`/compose?board=feedback`, expecting Anonymous to be hidden. Runtime inspection
showed the saved draft had restored General, changed the URL back to
`/compose?board=general`, and retained the title. General allows anonymity, so
the visible control agreed with the actual destination and ADR 0052.

The corrected test verifies that restoration explicitly, discards the draft
through the normal control, and then checks the fresh Feedback form. It also
checks that switching from a checked General anonymity choice to Feedback hides
the chip and disclosure, disables and clears the checkbox, and leaves the
choice unchecked when General is selected again. A server-rendered case checks
Feedback and General without JavaScript, including a reachable submit control.

[Baseline diagnosis](baseline-diagnosis.json) records the original failure and
the runtime state. Application behavior is preserved.

## UTC budget fixture correction

The first full PHP run found one unrelated concurrency-test failure shortly
after UTC midnight. Its fixture reserved today's budget but recorded a request
eleven minutes earlier, in yesterday's window. The worker correctly refuses to
charge a current-day budget for a prior-day abandoned request.

The fixture now reserves in the recorded request's window and checks current-day
accounting according to that date, while retaining its failed/interrupted-state
assertions and adding an assertion that no new provider call occurred. Existing
deterministic budget tests cover same-day settlement and prior-day no-op behavior.
The [initial full failure](checks/php-full-before-fixture-fix.log),
[focused reproduction](checks/php-concurrency-before-fixture-fix.log), and
[passing budget/concurrency checks](checks/php-budget-concurrency.log) are retained.
