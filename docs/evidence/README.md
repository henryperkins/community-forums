# Evidence archive

This directory preserves dated verification, audit, release, and rehearsal
records. A result applies to the source, environment, and command stated in
its evidence packet; it does not by itself describe the current checkout.

Use `FeatureFlags::DEFAULTS` ([`../../src/Core/FeatureFlags.php`](../../src/Core/FeatureFlags.php)),
the relevant ADR and runbook, or [`../../PRODUCT.md`](../../PRODUCT.md) for
current availability. Completed Phase 1–4 acceptance records are consolidated in
[`../history/PHASE_1-4_HISTORY.md`](../history/PHASE_1-4_HISTORY.md), and the
retired Phase 5 status ledger is archived beside it at
[`../history/PHASE_5_STATUS.md`](../history/PHASE_5_STATUS.md). Each
dated package remains intact as the supporting proof for its own release or
decision.
