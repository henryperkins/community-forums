# Phase 5 program records

This directory preserves Phase 5 entry-gate artifacts, threat models, and
implementation records. Gate A was accepted and default-on in July 2026, with
acceptance in [ADR 0017](../adr/0017-phase-5-gate-a-closeout.md) and the
default-on decision in [ADR 0018](../adr/0018-phase-5-gate-a-default-on.md). The
Phase 5 status ledger that tracked it is archived, no longer maintained, at
[`../history/PHASE_5_STATUS.md`](../history/PHASE_5_STATUS.md).

The records here establish their original decisions and evidence. Do not infer
current feature flags or outstanding work from their dated status lines; use
`FeatureFlags::DEFAULTS`, the owning runbook, and the ADRs in `docs/adr/`.
