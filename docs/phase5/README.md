# Phase 5 program records

This directory preserves Phase 5 entry-gate artifacts, threat models, and
implementation records. Gate A was accepted and default-on in July 2026; its
current runtime and rollout state is maintained in
[`../../PHASE_5_STATUS.md`](../../PHASE_5_STATUS.md), with acceptance in
[ADR 0017](../adr/0017-phase-5-gate-a-closeout.md) and the default-on decision
in [ADR 0018](../adr/0018-phase-5-gate-a-default-on.md).

The records here establish their original decisions and evidence. Do not infer
current feature flags or outstanding work from their dated status lines; use
`FeatureFlags::DEFAULTS`, the owning runbook, and the Phase 5 status record.
